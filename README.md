# 📈 股票分析-Web

> 一个在线股票记录网站，提供行情浏览、K线查看与数据管理功能。

## 📝 项目介绍

本项目是一个基于 Web 的股票记录平台，用户可以浏览股票行情列表，通过第三方网站查看个股 K 线图详情，并对股票记录进行管理。页面主体包含**搜索表单**与**行情表格**两大模块。

## ✨ 功能特性

### 🔍 搜索表单

支持按以下条件筛选股票记录：

- **代码**：股票代码
- **名称**：股票名称
- **标签**：自定义标签
- **板块**：下拉选择板块（一只股票可归属多个板块）
- **分类**：下拉选择分类（一只股票可归属多个分类）

### 📊 行情表格

展示股票行情的主要列：

| 列 | 说明 |
| --- | --- |
| 代码 | 股票代码 |
| 名称 | 股票名称 |
| 标签 | 自定义标签 |
| 板块 | 所属板块（可多个） |
| 分类 | 所属分类（可多个） |
| 价格 | 当前价格 |
| 成交量 | 成交量 |
| 成交额 | 成交金额 |
| 涨跌幅 | 涨跌幅度（%） |
| 涨跌额 | 涨跌金额 |
| 操作 | 详情、删除 |

### 🛠️ 操作说明

- **详情** 📉：通过 **iframe 弹窗** 嵌套第三方网站的 K 线图，或以 **新窗口** 打开第三方网站查看
- **删除** 🗑️：弹出确认框，确认后删除该行记录

> ℹ️ 备注：本系统暂无直接渲染图表的功能，K 线图均通过第三方网站页面（iframe 嵌套 / 新窗口打开）实现。

## 🎨 UI 风格

极简风（Minimalist），以深色背景为主，克制使用高亮色：

| 元素 | 色值 | 用途 |
| --- | --- | --- |
| 背景色 | `#0D1117` | 页面主背景 |
| 高亮色 | `#50A0FF` | 主高亮（强调文字、按钮、选中态等） |
| 高亮色 | `#7D6FE9` | 次高亮（标签、辅助强调等） |

## 🧰 技术栈

| 技术 | 说明 |
| --- | --- |
| 🟩 Node.js | 运行时环境（本项目采用 **v24.9.0**） |
| ⚡ Vite | 前端构建工具 |
| 🟢 Vue3 | 渐进式前端框架（组合式 API） |
| 🐜 Ant Design Vue | UI 组件库 |
| 📡 Axios | HTTP 请求库，用于对接后端股票数据接口 |
| 🎨 Less | CSS 预处理语言 |

## 🚀 快速开始

> ⚙️ 环境要求：**Node.js v24.9.0**（建议使用 nvm 管理版本：`nvm install 24`）

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产构建
npm run build

# 本地预览构建产物
npm run preview
```
